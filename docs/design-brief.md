# Audinote — デザインブリーフ

## アプリ概要

USBボイスレコーダーを接続すると、音声ファイルを自動で取り込み、AIが文字起こし・要約してMarkdownファイルとして保存するデスクトップアプリ。

- **プラットフォーム:** macOS / Windows（Electron製）
- **技術スタック:** Electron + React + TypeScript
- **AIエンジン:** Google Gemini API
- **対応音声形式:** WAV / MP3 / M4A

---

## ワークフロー

```
USBを刺す
  ↓
アプリが自動検知
  ↓
音声ファイルを取り込み
  ↓
Gemini APIで文字起こし（長い音声は自動分割）
  ↓
Gemini APIで要約
  ↓
Markdownファイルとして保存（ファイル名は日付＋内容から自動生成）
```

### 処理の詳細

| ステップ | 内容 |
|---|---|
| USB検知 | 指定したレコーダー名でデバイスを識別 |
| ファイル取り込み | WAV/MP3/M4A を内部フォルダへ移動 |
| 文字起こし | 20分以下はそのままAPI送信、20分超は1分オーバーラップで分割処理 |
| 要約 | プロンプトテンプレートを使ってGemini APIで要約 |
| ファイル名生成 | 要約内容からAIがファイル名を提案（例: `20260407_会議議事録.md`） |
| ログ記録 | 処理結果をJSONLファイルに追記 |

## 画面構成

### 1. メイン画面（ホーム）

アプリを開いたときの画面。常駐してUSBを待ち受ける。

**表示要素:**
- USBデバイスの接続状態（未接続 / 接続中 / 認識済み）
- 現在の処理状態とプログレス
  - 待機中
  - ファイル取り込み中（ファイル名・件数）
  - 文字起こし中（進捗 %・何分割中の何番目か）
  - 要約中
  - 完了 / エラー
- 直近の処理結果サマリー（最後に処理したファイル名・日時）

**操作:**
- 手動で音声ファイルを指定して処理する（USB不要のフォールバック）

---

### 2. 履歴画面

処理済みファイルの一覧。

**表示要素:**
- 処理済みファイルのリスト
  - 元の音声ファイル名
  - 生成されたMarkdownファイル名
  - 処理日時
  - ステータス（成功 / 失敗）
- 失敗したファイルの再処理ボタン

**操作:**
- Markdownファイルをワンクリックで開く
- 失敗ファイルの再処理

---

### 3. 設定画面

初回セットアップや設定変更のための画面。

**設定項目:**

| 項目 | 説明 |
|---|---|
| Google API キー | Gemini APIキー（入力値はマスク表示） |
| レコーダー名 | USBデバイスのボリューム名（例: `IC RECORDER`） |
| 音声ファイルのサブフォルダ | レコーダー内のサブディレクトリ（例: `RECORD`） |
| Markdown出力先 | 保存フォルダ（フォルダ選択ダイアログ） |
| 要約プロンプト | カスタマイズ可能なプロンプトテンプレート（テキストエリア） |

## UX上の重要ポイント

### 処理中の可視性
現状（シェルスクリプト版）の最大の不満が「何が起きているかわからない」こと。処理の各ステップが視覚的にわかるUIが必須。

- ステップごとのインジケーター（文字起こし中なのか要約中なのか）
- 長い音声の場合は分割処理の進捗（例: 「チャンク 2/5 を処理中」）
- 完了時の通知（OSのネイティブ通知）

### 初回セットアップ
現状はAPIキー・フォルダパス・レコーダー名など設定が多く面倒。ウィザード形式で順番に案内する初回セットアップフローがあると良い。

### エラー時
APIエラーやファイル読み込み失敗など、エラー内容をわかりやすく表示し、再試行ボタンを提供する。

## 参考：処理ステータスのデータ構造

処理結果は以下の形式でJSONLに記録される（履歴画面の元データ）：

```json
{
  "source_audio": "REC_001.wav",
  "output_markdown": "20260407_会議議事録.md",
  "processed_at": "2026-04-07T14:30:00",
  "status": "summary_success"
}
```

ステータス種別:
- `summary_success` — 完全成功
- `transcribe_failure` — 文字起こし失敗
- `summary_failure` — 要約失敗
- `move_to_done_failure` — ファイル移動失敗
- `failure` — その他エラー
